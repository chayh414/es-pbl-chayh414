# PBL 시작 카드

- 프로젝트 주제: 빈티지·세컨핸드 의류 상품 검색
- 사용자는 누구인가: 가격 대비 상태 좋은 빈티지·디자이너 브랜드 의류를 찾는 구매자
- ES로 찾게 할 문서 1건은 무엇인가: 중고 의류 상품 1건 (예: 리바이스 501 빈티지 데님 자켓, A급, 정가 대비 20% 할인된 45,000원, 번개장터 판매)
- 사용자가 입력할 검색 질문 1: 3만원 이하, A급 이상 상태의 데님 자켓을 찾고 싶다
- 사용자가 입력할 검색 질문 2: 90년대 빈티지 브랜드 옷을 판매자 평점 높은 순으로 보고 싶다
- 사용자가 입력할 검색 질문 3: 설명에 하자(얼룩, 보풀 등) 언급이 없는 상품만 보고 싶다
- 필터에 사용할 분류 필드 후보: category, condition, brand, brand_tier, era, material, platform
- 정렬에 사용할 숫자·날짜 필드 후보: price, seller_rating, listed_date
- Dashboard에서 답할 질문 1: 카테고리별 평균 가격은 얼마인가?

## 범위 확인

- 웹사이트 전체를 만드는 과제가 아닙니다. ES index, 검색 요청, 분석·Dashboard를 완성합니다.
- 실제 개인정보·고객 데이터는 사용하지 않습니다.
- 최소 1,000건, 권장 5,000~10,000건의 합성 데이터를 사용합니다.
