# 빈티지 의류 마켓 검색

## 1. 프로젝트 소개

- 문제와 사용자: 가격 대비 상태 좋은 빈티지/중고 의류를 찾는 구매자가, 브랜드·사이즈·상태등급·가격대로 원하는 옷을 빠르게 찾고 싶어한다.
- ES로 검색할 문서 1건: 중고 의류 상품 1건 (예: 리바이스 501 빈티지 데님 자켓, A급, 정가 대비 20% 할인된 45,000원, 번개장터 판매)
- 이 주제를 선택한 이유: 일반 쇼핑몰과 달리 재고가 단일 재고이고, 상태등급(condition)·연대(era)·하자(defects) 같은 중고 특화 필드가 있어 필터·검색 조건이 더 다양하게 설계된다.
