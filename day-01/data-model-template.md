# 데이터 모델 초안

## 1. 문서 단위

- 검색 결과 한 건은 무엇인가: 중고(빈티지·세컨핸드) 의류 상품 1건
- 이 문서 한 건이 사용자에게 보여 주는 정보는 무엇인가: 상품명, 브랜드/브랜드 등급, 상태 등급(S/A/B급), 판매가, 정가, 연대(era), 판매 플랫폼, 판매자 평점, 하자 설명 등 — 구매자가 "이 옷을 살지 말지" 판단하는 데 필요한 정보 전체

## 2. 대표 문서 예시

```json
{
  "item_name": "리바이스 501 빈티지 데님 자켓",
  "category": "아우터",
  "brand": "Levi's",
  "brand_tier": "일반",
  "size": "L",
  "color": "블루",
  "condition": "A급",
  "price": 45000,
  "original_price": 56000,
  "era": "90s",
  "material": "데님",
  "platform": "번개장터",
  "seller_rating": 4.8,
  "listed_date": "2026-08-20",
  "sold": false,
  "description": "90년대 리바이스 501 데님 자켓, 워싱 상태 양호",
  "defects": ""
}
```

## 3. 핵심 field와 역할

| field | 예시 값 | 검색에서 맡는 역할 | ES type 후보 | 선택 이유 |
|---|---|---|---|---|
| item_name | "리바이스 501 빈티지 데님 자켓" | 전문 검색 | text | 상품명으로 자유 검색해야 하므로 |
| category | "아우터" | 정확 조건 (필터) | keyword | 카테고리는 정해진 값 중 하나를 정확히 선택/필터링하는 용도 |
| condition | "A급" | 정확 조건 (필터) | keyword | S/A/B급 등급 그대로 필터링, 순서 비교는 하지 않음 |
| price | 45000 | 범위 / 정렬 | integer | "3만원 이하" 같은 범위 조건과 가격순 정렬에 사용 |
| seller_rating | 4.8 | 정렬 | float | 평점 높은 순 정렬에 사용 |
| era | "90s" | 정확 조건 (필터) | keyword | 90년대/2000년대 등 정해진 값으로 필터링 |
| defects | "" | 전문 검색 / 존재 여부 확인 | text | 하자 설명 텍스트에 특정 단어(얼룩, 보풀 등)가 있는지, 또는 비어있는지 확인 |

## 4. 검색 질문과 field 연결

| 검색 질문 | 사용할 field | 확인할 역할 |
|---|---|---|
| 3만원 이하, A급 이상 상태의 데님 자켓을 찾고 싶다 | price, condition, category, material/item_name | price는 범위 조건, condition/category는 정확 조건(필터), item_name·material은 검색어 |
| 90년대 빈티지 브랜드 옷을 판매자 평점 높은 순으로 보고 싶다 | era, seller_rating | era는 정확 조건(필터), seller_rating은 정렬 기준 |
| 설명에 하자(얼룩, 보풀 등) 언급이 없는 상품만 보고 싶다 | defects | 특정 단어 포함 여부 검색 또는 값이 비어있는지 확인(제외 조건) |

## 5. 제외할 데이터

- 수집하거나 저장하지 않을 개인정보: 판매자 실명, 연락처(전화번호/카카오톡 ID), 실제 거래 계좌번호, 실제 배송지 주소
- 제외 이유: 실제 개인 판매자·구매자를 특정할 수 있는 정보이며, 이 프로젝트는 실제 거래가 아닌 합성 데이터 기반 검색 실습이므로 개인정보를 다룰 필요가 없음. seller_rating처럼 검색·정렬에 필요한 값만 합성 데이터로 사용
